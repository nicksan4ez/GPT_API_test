# Telegram Channel Analyzer

Веб-приложение для анализа экспорта Telegram каналов с использованием современных методов NLP.

## 🚀 Возможности

- **Частотный анализ слов** - выявление наиболее употребляемых слов и словосочетаний
- **Анализ тональности** - определение эмоциональной окраски сообщений
- **Тематическое моделирование** - автоматическое выделение основных тем обсуждений
- **Анализ связей между словами** - построение графа связей и определение ключевых слов
- **Интерактивные графики** - визуализация результатов с помощью Plotly
- **Веб-интерфейс** - удобный интерфейс для загрузки файлов и просмотра отчетов

## 📋 Требования

- Python 3.8+
- Flask
- NetworkX
- Plotly
- NumPy
- Matplotlib
- Scikit-learn (опционально)
- NLTK (опционально)

## 🛠 Установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/yourusername/telegram-analyzer.git
cd telegram-analyzer
```

2. Создайте виртуальное окружение:
```bash
python -m venv .venv
source .venv/bin/activate  # для Linux/Mac
# или
.venv\Scripts\activate  # для Windows
```

3. Установите зависимости:
```bash
pip install -r requirements.txt
```

## 🎯 Использование

### Веб-интерфейс

1. Запустите веб-приложение:
```bash
python web_app.py
```

2. Откройте браузер и перейдите по адресу `http://localhost:5000`

3. Загрузите JSON файл экспорта Telegram канала

4. Просмотрите результаты анализа с интерактивными графиками

### Командная строка

```python
from working_telegram_analyzer import SimplifiedTelegramAnalyzer
import json

# Загрузите данные
with open('telegram_export.json', 'r', encoding='utf-8') as f:
    data = json.load(f)

# Создайте анализатор
analyzer = SimplifiedTelegramAnalyzer()

# Выполните анализ
results = analyzer.analyze_comprehensive(data)

# Получите текстовый отчет
report = analyzer.generate_telegram_report(results)
print(report)
```

## 🔧 Форматы экспорта

Поддерживаются следующие форматы экспорта Telegram:

- **Telegram Desktop** - стандартный JSON экспорт
- **Telegram Bot API** - экспорт через бота
- **Пользовательские форматы** - адаптируется к различным структурам данных

## 📊 Типы анализа

### 1. Частотный анализ
- Топ наиболее употребляемых слов
- Анализ биграмм (словосочетаний)
- Статистика по длине сообщений

### 2. Анализ тональности
- Классификация сообщений: позитивные, негативные, нейтральные
- Статистика по эмоциональной окраске
- Визуализация распределения тональности

### 3. Тематическое моделирование
- Автоматическое выделение тем с помощью LDA
- Ключевые слова для каждой темы
- Распределение документов по темам

### 4. Анализ связей слов
- Граф связей между словами
- Метрики центральности (degree, betweenness, closeness)
- Выявление ключевых узлов в семантической сети

## 🎨 Визуализация

- **Интерактивные графики** с помощью Plotly
- **Облако слов** для визуализации частотности
- **Графы связей** для отображения семантических связей
- **Диаграммы распределения** тональности и тем

## 🔧 Настройки

Вы можете настроить анализатор, изменив параметры в коде:

```python
# Минимальное количество совпадений для связей слов
analyzer.analyze_word_connections(texts, min_cooccurrence=3)

# Количество тем для моделирования
analyzer.perform_topic_modeling(texts, num_topics=7)
```

## 🐛 Устранение неполадок

### Проблемы с кодировкой
Убедитесь, что файл экспорта сохранен в UTF-8 кодировке.

### Ошибки импорта
Установите все зависимости из requirements.txt:
```bash
pip install -r requirements.txt
```

### Проблемы с памятью
Для больших файлов экспорта может потребоваться увеличение памяти Python или обработка данных частями.
